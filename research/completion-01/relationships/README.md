# Explicit sourced relationships: accepted-status reuse

This source-wide tranche categorizes existing accepted, dated political-status statements as relationships. It retrieves no sources and makes no new historical assertions. Exact wording, dates, source IDs and notes are preserved. No counterpart entity ID, sovereignty or succession is inferred.

The predicate requires an explicit affiliation and a named literal party/group. Generic independence, unnamed affiliations, future-only relationships and uncertain records remain excluded. Contested-control qualifications remain in the original statement.

The frozen cohort contains 222 structured records targeting 448 full-year missing slots, with partial-year support reported separately. Original interval dates and precision are copied exactly within the entity and 1800-1960 atlas envelope.

selection.json preserves original facts, indexes, canonical hashes and legacy claim IDs. certificate-draft.json is not acceptance. certificate.json records independent coordinator category review of the exact cohort. Previously accepted source bodies were reused, not represented as new research.

The validator's literal-party exception requires an exact documented original status reference, original record hash, wording, source order, notes and bounded dates. Entity-linked relationships retain their target-ID checks. Integration uses the existing serial atomic writer and recovery journal.
