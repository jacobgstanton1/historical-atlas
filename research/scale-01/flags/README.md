# Historical flag acquisition, scale checkpoint 01

This directory contains untrusted, bounded flag evidence bundles for coordinator review. They are compatible claim/source records for incorporation into complete schema-v2 dossier packages; they are not accepted packages, and do not independently satisfy comprehensive job investigation requirements.

Run `node research/scale-01/flags/acquire.mjs` to resume the allowlisted acquisition manifest. Existing bytes are reused, expected SHA-256 values are verified, failed resources are recorded separately, and unrelated acquisitions continue. HTTPS redirects fail closed; a coordinator must review changed source routes. The script writes only local `cache/`, `staged-assets/`, and its acquisition ledger. It never installs production assets or interprets historical meaning. Run the adjacent Node test file for focused acquisition checks.

The manifest separates historical chronology sources from asset description/licence pages and actual SVG downloads. A Commons file page proves asset provenance/licensing, not historical adoption or territorial sovereignty. Original assets remain unchanged. Preserved Campaign 2 assets are reused where applicable, but fresh historical acceptance is required. The source body cache is ignored by Git: it is a local reading aid, not republication of copyrighted historical documents.

Coordinator review must independently read the historical body and individual licence, verify type (national/state/civil/office flags differ), inspect the SVG, bind acceptance to exact package and asset hashes, reconcile source URLs with existing registries, and then install reviewed assets through serialized integration. `asset-validation.json` proves only asset/provenance checks in an isolated temporary mirror; it is not historical acceptance or proof of a complete dossier. All bundle claims retain conservative date bounds and schematic-colour qualifications.

Nine entities currently provide thirteen bounded interval claims. France deliberately excludes restoration, 1848 ordering ambiguity and competing wartime authorities. Norway is explicitly a rectangular civil ensign, not the split state ensign. Sweden is explicitly the union-era merchant/civil ensign. Swiss post-1889 arms are not projected onto the 1848–1889 design; the disputed adoption-year precision is left outside coverage. The modern Italian asset was acquired during investigation but is held unused: the 1946–2003 asset is used for republican claims. Existing Pakistani, Tongan, Brazilian and other already-integrated flags remain unchanged; duplication is avoided.

No production data, runtime, UI or Git state was modified by this research worker. Root coordinator chooses justified integrations and recoverable production checkpoints.
