# Primary statutory review of Brazil’s21-star flag

Complete decree bodies were read using the web tool on2026-10-01. No source excerpts or PDFs are republished here. Decree4/1889 Article1 establishes the21-star national design. Decree48124/1960 confirms its retention in1942 and adds the22ndstar effective21April1960. Together they support the bounded1893–1929design independently of Commons file naming. The original package is preserved before revision. Flag label, historical entity, selected interval, type and SHA-256 bytes are unchanged.
